# Booking window, one-day blocks, registration v2, unified login and editable business code

Objective: booking window of 15 days (Colombia time), one-day blocks managed only by the admin, new company registration (admin username, Colombian department/municipality, per-day schedule, 1–10 employees, admin-chosen business code), unified login, AGENTS.md. Backend only.
Branch: `feature/registro-empresa` (base `e1a3a10`). Delivery: single branch, work-unit commits, push authorized by the user. Test runner: none for this feature (user: "No escribas pruebas automáticas ni pidas revisiones"); checks are manual HTTP calls against the local server with `PRUEBA*` data removed afterwards, plus `npm run typecheck`.

## Specs

- S1 — "Límite de reservas: un cliente solo puede reservar desde hoy hasta 14 días después (15 días en total contando hoy, hora de Colombia). Rechaza reservas fuera de ese rango con un mensaje claro."
- S2 — "Además de los bloqueos que se repiten cada semana, permite bloqueos de "solo ese día": una hora específica de una fecha, o el día completo de una fecha."
- S3 — "SOLO la administradora puede crear y borrar bloqueos. Los barberos no pueden bloquear; como mucho pueden ver su propio horario."
- S4 — "Las reservas deben rechazar cualquier hora bloqueada de los dos tipos, y el endpoint público de bloqueos debe devolver ambos tipos (sin el motivo)."
- S5 — "Quita el NIT y el teléfono y correo de contacto del negocio."
- S6 — "Acceso de la administradora: correo, nombre de usuario y contraseña. El usuario solo puede tener letras, números, punto y guion bajo (4 a 20 caracteres) y no puede repetirse con ningún otro usuario, sea administradora o personal."
- S7 — "Número de empleados: entre 1 y 10."
- S8 — "Agrega departamento y ciudad (municipio) de Colombia, además de la dirección."
- S9 — "Horario de atención por día: cada día de la semana puede estar abierto o cerrado, y cada día abierto tiene su propia hora de apertura y cierre. Las reservas deben respetar ese horario."
- S10 — "Si estos campos ya existen en empresas registradas, migra los datos sin perderlos. A las administradoras que ya existen, crea un usuario a partir de su correo y dime cuál quedó."
- S11 — "Inicio de sesión: crea un login único que reciba "correo o usuario" y contraseña, y detecte si es la administradora o alguien del personal. Mantén funcionando los logins actuales para no romper nada."
- S12 — "Código del negocio para clientes: ya no se genera automáticamente; lo escribe la administradora al registrarse y lo puede cambiar en "Mi negocio". Reglas: solo letras y números, sin espacios, máximo 10 caracteres, sin distinguir mayúsculas de minúsculas, y que no lo tenga otro negocio. Crea un endpoint para verificar si un código está disponible. A las empresas que ya existen, déjales su código actual."
- S13 — "Actualiza AGENTS.md con todos los cambios (endpoints, campos y mensajes de error)."
- S14 — "Haz commit y push. Dame un resumen sencillo." Constraints: "Si cambias la base de datos, crea una migración nueva, ejecútala con npm run db:migrate y confirma que funcionó."; test data names start with "PRUEBA" and are deleted at the end.

Assumptions (no open product decision; recorded so they can be changed later):
- A1 — Department and municipality are validated against the official DANE DIVIPOLA list (datos.gov.co `gdxc-w37w`, 33 departments, 1122 municipalities) and stored with the official name. A public read-only `GET /api/v1/ubicaciones` lists them so the app can offer them.
- A2 — The per-day schedule replaces `dias_atencion`, `horario_apertura` and `horario_cierre` (new table `horarios_empresa`). Responses keep `diasAtencion`, `horarioApertura` (earliest) and `horarioCierre` (latest) as derived read-only fields so the current app keeps working.
- A3 — A full-day block is stored as 00:00–24:00 (`todoElDia: true`). Weekly blocks may also be full-day.
- A4 — The unified login serves admin accounts and staff; a client account answers 403 pointing to the client login.
- A5 — Business code has no minimum length beyond 1 character; it is stored in uppercase.
- A6 — Existing companies without `dias_atencion` were bookable every day, so they get all 7 days open with their previous hours.
